Install and start building.

Choose the command for your operating system, then create and run your first JavaScript or TypeScript project.

# macOS and Linux
curl -fsSL https://deno.land/install.sh | sh

# Windows PowerShell
irm https://deno.land/install.ps1 | iex

# Confirm installation
deno --version
